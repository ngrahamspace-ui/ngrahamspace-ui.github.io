# Save the Date Invite

This project is a simple one-page website designed to serve as a "Save the Date" invitation. It features an interactive envelope that opens to reveal the invitation details when clicked.

## Project Structure

```
save-the-date-invite
├── src
│   ├── index.html        # Main HTML document for the website
│   ├── styles
│   │   └── style.css     # Styles for the website
│   └── scripts
│       └── main.js       # JavaScript for interactive functionality
├── assets
│   └── fonts             # Directory for custom fonts
└── README.md             # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd save-the-date-invite
   ```

3. **Open the `index.html` file** in your web browser to view the invitation.

## Customization

- You can customize the invitation details by editing the content in `src/index.html`.
- Modify the styles in `src/styles/style.css` to change the appearance of the envelope and invite.
- Update the JavaScript in `src/scripts/main.js` if you want to change the interactive behavior.
